2 Quick Start Workflow

Discovery
→
Fit Models
→
Design Crosses
→
Figures & Tables
  1. Prepare PLINK genotypes, GFF3 + FASTA reference, GWAS hits, and phenotypes.
  2. haplobreed_analysis() identifies genes with superior haplotypes per trait.
  3. hbr_fit_models() fits two-kernel GBLUP; hbr_cross_design() ranks crosses.
  4. Export manuscript tables (hbr_build_manuscript_tables()) and figures.

3 Data Input

Supported formats
  • Genotypes: PLINK (.bed/.bim/.fam), .raw, VCF, HapMap, in-memory matrix
  • Reference: GFF3 + CDS/pep/genome FASTA (local, MSU7, RAP-DB, Ensembl Plants)
  • GWAS hits: data.frame with SNP, Chromosome, Position, P
  • Phenotypes: data.frame with ID and one trait column per run
Example: load data
gwas  <- read.csv("gwas_hits.csv")
pheno <- read.csv("phenotypes.csv")

4 Superior-Haplotype Discovery

Identify genes carrying superior haplotypes
res <- haplobreed_analysis(
  plink_prefix     = "geno_259",
  reference_source = "msu7",
  gwas_snps        = gwas,
  phenotype_data   = pheno,
  trait_col        = "PHT",
  direction        = "lower",
  n_perm           = 1000L,
  min_cohens_d     = 0.3,
  require_fdr      = TRUE,
  output_dir       = "analysis_PHT")
Inspect results
head(res$summary)
res$superior_summary

5 Genomic Selection

Two-kernel GBLUP with honest nested CV
fit <- hbr_fit_models(
  trait_dirs   = c(PHT = "analysis_PHT",
                   GY  = "analysis_GY"),
  plink_prefix = "geno_259",
  weights      = c(PHT = 1, GY = 2),
  cv_repeats   = 10L,
  cv_folds     = 5L,
  strict       = TRUE,
  output_dir   = "fit_out")
Model comparison
  • M0 — genome-wide GBLUP baseline
  • M2 — two-kernel (naive feature selection)
  • M3 — in-fold gate replay (honest)
fit$cv_summary
fit$cv_compare

6 Cross Design

Haplotype blocks, usefulness, and pyramiding
design <- hbr_cross_design(
  fit,
  haploblock_method = "recomb+gabriel",
  mating            = "DH",
  relatedness_max   = 0.30,
  top_crosses       = 20L,
  run_set_selection = TRUE,
  set_size          = 8L)
Inspect decisions
design$crosses        # top crosses
design$parents        # ranked parents
design$blocks         # target blocks
design$selected_set   # SA parent set

9 Complete Example

# 1. Identify superior haplotypes
res <- haplobreed_analysis(
  plink_prefix     = "geno_259",
  reference_source = "msu7",
  gwas_snps        = gwas,
  phenotype_data   = pheno,
  trait_col        = "PHT",
  direction        = "lower",
  output_dir       = "analysis_PHT")

# 2. Fit genomic prediction models
fit <- hbr_fit_models(
  trait_dirs   = c(PHT = "analysis_PHT"),
  plink_prefix = "geno_259",
  output_dir   = "fit_out")

# 3. Design crosses
design <- hbr_cross_design(fit,
  haploblock_method = "recomb+gabriel")

# 4. Manuscript tables
hbr_build_manuscript_tables(
  rds_file    = "analysis_PHT/pipeline_result_for_breeding.rds",
  output_file = "tables.xlsx")
